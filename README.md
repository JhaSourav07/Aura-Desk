# Aura Desk

[![Flutter](https://img.shields.io/badge/Flutter-02569B?style=for-the-badge&logo=flutter&logoColor=white)](https://flutter.dev/)
[![Dart](https://img.shields.io/badge/Dart-0175C2?style=for-the-badge&logo=dart&logoColor=white)](https://dart.dev/)

A beautiful dark-mode UI prototype for controlling a smart multipurpose lamp using your smartphone. This Flutter application showcases an elegant interface for managing various smart devices including lamps, fans, printers, and alarms.

> **⚠️ Important Note:** This is a **frontend prototype only**. The application does not include any backend logic, Bluetooth connectivity, or actual device control functionality. The UI is purely interactive for demonstration and design purposes.

## Features

- 📊 **Dashboard** - Central hub for monitoring and controlling all your smart devices at a glance
- 💡 **Lamp Control** - Intuitive interface for managing your smart lamp settings (brightness, color, etc.)
- 🌀 **Fan Control** - Easy-to-use controls for your smart fan
- 🖨️ **Printer Management** - Quick access to printer controls and status
- ⏰ **Alarms** - Set and manage alarms through your smart lamp system

## Getting Started

Follow these instructions to get the project up and running on your local machine.

### Prerequisites

- [Flutter SDK](https://flutter.dev/docs/get-started/install) installed on your machine
- A code editor (VS Code, Android Studio, etc.)
- An emulator or physical device for testing

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/JhaSourav07/Aura-Desk.git
   cd Aura-Desk
   ```

2. **Install dependencies**
   ```bash
   flutter pub get
   ```

3. **Run the application**
   ```bash
   flutter run
   ```

   The app should now launch on your connected device or emulator.
